# About

This repository contains a self-service workflow for participants of the **DevOpsDays Graz 2026**.

# Resources

| Workflow                                               | Description |
|--------------------------------------------------------| --- |
| `.github/workflows/create-repository-self-service.yml` | Issue driven workflow, used to create a new repository from a technology template (Docker, Maven,...). |

# Usage

1. Open an Issue via the [Issue UI](https://github.com/EBCONT-Conference/devopsdays.demo.self-service/issues).
2. Choose the "Create repository self-service" issue template.
3. Enter the Access Key that was shared with you during the DevOpsDays Graz 2026 event.
4. Pick a technology template (Docker, Maven, ...).
5. Click "Submit new issue".

### Results
- After submitting the issue, the workflow will automatically create a new repository based on the selected technology template. You will receive a notification once the repository is ready for use.
- When following the link to the newly created repository, you will be prompted to accept the invitation to join the repository/organization. Please accept the invitation to gain access.
- Woohoo, you now have a fully prepared repository with "write" access for your user!
